# doc-fill-bot

Исходники Telegram-бота для работы с шаблонами Word. В [bot.py](bot.py) реализованы меню, выдача доступа пользователям, хранение шаблонов и настроек полей в SQLite, прием данных для одного или нескольких документов. Там же есть вызов LibreOffice для конвертации DOCX в PDF.

Операции чтения маркеров вида `{{ФИО}}` и подстановки в документ оставлены заглушками в [document.py](document.py). Автополя для даты, инициалов и суммы прописью оставлены заглушками в [utils.py](utils.py). Загрузка шаблона сейчас останавливается на разборе маркеров.

## Запуск

Меню и управление доступом можно посмотреть с отдельным тестовым ботом. Для заполнения документов нужны реализации в `document.py` и `utils.py`, а для вывода в PDF нужен LibreOffice.

```bash
python -m pip install -r requirements.txt
cp .env.example .env
```

Укажите `BOT_TOKEN` и список Telegram ID администраторов `ADMIN_IDS` через запятую, затем выполните `python bot.py`. Код хранит шаблоны в `templates/`, результаты в `filled/` и настройки в `bot.db`.
