# doc-fill-bot

Telegram-бот для автоматического заполнения документов Word.

## Что делает

Загружаете шаблон договора или любого другого документа в формате DOCX, расставляете в нём маркеры вида `{{ФИО}}`, `{{ДАТА}}`, `{{СУММА}}`. Бот запоминает шаблон и поля. Когда нужно заполнить - отправляете данные одним сообщением построчно, получаете готовый документ.

Есть несколько автоматических полей, которые бот заполняет сам: сегодняшняя дата, фамилия с инициалами из полного ФИО, сумма прописью.

Можно хранить несколько шаблонов и заполнять их все одним сообщением с данными. Вывод в Word или PDF (через LibreOffice).

Доступ к боту выдаёт администратор.

## Требования

Python 3.10+, LibreOffice (для PDF)

## Стек

- Python 3.11+
- aiogram 3
- python-docx
- aiosqlite
- python-dotenv

## Запуск

```bash
pip install -r requirements.txt
cp .env.example .env
# заполните .env
python bot.py
```

## Переменные окружения

```
BOT_TOKEN=  # токен от @BotFather
ADMIN_IDS=  # Telegram ID администраторов через запятую
```

## Примечания

- Шаблоны хранятся в папке `templates/`
- Заполненные документы — в `filled/`
